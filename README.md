# Qalam AI

Qalam AI is an AI-powered heritage inscription understanding platform for Arabic inscriptions on historical monuments.

## Repository structure

- backend/: FastAPI application and domain services
- mobile/: Flutter app shell for camera, gallery, history, and overlays
- datasets/: dataset pipeline folders and scripts
- docs/: architecture and engineering documentation
- .github/workflows/: CI/CD scaffolding

## Milestones

1. Architecture and contracts
2. Backend API and service interfaces
3. Flutter app shell and navigation
4. Dataset pipeline and evaluation scaffolding
5. Deployment and documentation
